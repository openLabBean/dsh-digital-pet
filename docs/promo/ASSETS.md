# README 宣传素材

- `hero.png`：内置 imagegen 基于当前九位宠物绘制的宣传插画，不是实际界面截图。实际提示词见 `imagegen-record.json`。
- `meet-the-pets.png`：当前成年首帧素材与中英文名字的排版。短句为角色气质文案，不代表独立的 AI 性格系统。
- `little-rituals.png`：插件真实 feed、bathe、walk、cleanWaste 姿态图排版。
- `growing-together.png`：迪诺六个成长阶段的真实首帧排版。
- `hello-pets.gif`：九款成年图集的实际绘制帧，按确认过的动作序列编码。序列为 0/1050ms、1/65ms、2/90ms、3/65ms、4/125ms、5/125ms、4/125ms、5/125ms、6/145ms、7/170ms。GIF 自动循环供 GitHub 展示；实际插件悬停才播放。
- `character-reference.png`：宣传插画的角色身份参考图。
- `README-preview.html`：本地 GitHub 风格排版预览，正文来自根目录 README。
- `readme-desktop.png`、`readme-mobile.png`：桌面和手机宽度的排版检查截图。

README 图片均使用仓库相对路径，不依赖本机绝对地址或外部图床。这一轮只修改文档和宣传素材，没有修改插件逻辑及运行时素材。

## English documentation

The `.en.png` and `.en.gif` variants reuse the same existing pet artwork and animation frames with English labels. `README-preview.html` opens in Simplified Chinese; its language links navigate to `README-preview.en.html` and back. The GitHub source files are root `README.md` and `README.en.md`.
